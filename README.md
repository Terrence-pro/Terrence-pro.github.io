A static personal homepage with no build step or installed dependencies. Open index.html in a browser to preview it locally; an internet connection is optional (external fonts fall back to system fonts).

The site uses the public-facing username Terrence-pro and the introduction “一个神秘奇男子” supplied by the owner. Before publishing, review every line and remove anything you do not want public. Do not put your student ID, private homework, passwords, or tokens here.

To publish, create a public GitHub repository named Terrence-pro.github.io, put index.html and style.css at its root (the README is optional in the public repository), then in repository Settings → Pages, choose Deploy from a branch, select the branch containing these files and the root folder /, and save.
